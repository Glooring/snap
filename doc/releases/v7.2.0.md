# snap v7.2.0

This is the first public OSS-readiness release for Snap's current Rust CLI.

## Highlights

- Git-powered local project checkpoints with `snap new`, `snap list`, `snap diff`, and `snap restore`.
- Safer restore workflow with `restore --dry-run` and rescue snapshots for dirty worktrees.
- `snap doctor` health checks for Git/Snap metadata, including JSON and CI-friendly modes.
- Daily Git workflow helpers for status, save, history, branch, remote, sync, and release tasks.
- Public documentation for AI-agent workflows, beginner workflows, safety model, known limitations, installation, packaging, and cross-platform notes.
- CI-backed validation on Ubuntu and Windows.

## Known Limitations

- Snap still uses the `snap` binary name. On Linux/WSL2, this can conflict with Canonical Snapcraft's `snap`; see `doc/INSTALLATION.md` for conflict-safe `gitsnap` install examples.
- Snap snapshots still use Git tags with marker-first filtering. Namespaced snapshot refs remain a future migration.
- Checksum generation is handled by the release workflow for this release; local release-upload automation still has a follow-up issue.
