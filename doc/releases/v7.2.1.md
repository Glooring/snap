# snap v7.2.1

This patch release improves branch/snapshot discoverability and adds a clearer terminal graph for understanding local branch history.

## Highlights

- Added `snap history --all-branches` to show a Git graph across local branches and snapshot tags.
- Added `snap history --branch <name>` to inspect one local branch without switching to it.
- Made `snap --help` point directly to command-specific help such as `snap list --help`, `snap history --help`, and `snap branch --help`.
- Clarified `snap list --all-branches` output: `-` in the Branch column means the snapshot tag exists, but no local branch reaches it.
- Expanded integration coverage for branch-aware help, list filtering, history graph behavior, and unreachable snapshot display.

- `SHA256SUMS.txt`

Verify downloaded assets with:

```bash
sha256sum -c SHA256SUMS.txt
```

The Linux asset is built on Ubuntu 24.04 and requires glibc 2.39 or newer. On older Linux distributions, build from source with `cargo build --release`.

## Compatibility

- Existing snapshots, snapshot tags, metadata refs, restore behavior, and branch behavior are unchanged.
- The new history flags are read-only.
- The `snap list --all-branches` placeholder changed back to `-` with an explicit legend to avoid confusion with a possible branch name.
