# snap v7.2.2

This release adds macOS as a first-class release platform and refreshes the README with a realistic visual demo.

## Highlights

- Added macOS CI on GitHub-hosted runners.
- Added `snap release macos` for native macOS release asset generation.
- Added GitHub release assets for Apple Silicon and Intel macOS.
- Extended public release smoke tests to run the macOS portable binaries in disposable Git repositories.
- Added a README demo generated from a disposable 382-file repository with 130 Snap snapshots.

## Release Assets

This release publishes:

- `snap-v7.2.2-linux-x86_64`
- `snap-v7.2.2-linux-x86_64.tar.gz`
- `snap-v7.2.2-windows-x86_64.exe`
- `snap-v7.2.2-windows-x86_64-setup.exe`
- `snap-v7.2.2-windows-x86_64.msi`
- `snap-v7.2.2-macos-aarch64`
- `snap-v7.2.2-macos-aarch64.tar.gz`
- `snap-v7.2.2-macos-x86_64`
- `snap-v7.2.2-macos-x86_64.tar.gz`
- `SHA256SUMS.txt`

Verify downloaded assets with:

```bash
sha256sum -c SHA256SUMS.txt
```

On macOS, use:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

The macOS binaries are unsigned and not notarized. If macOS quarantine blocks a downloaded binary, inspect the file path and checksum first, then remove quarantine only for the downloaded Snap binary you intend to run.

## Compatibility

- Existing snapshots, snapshot tags, metadata refs, restore behavior, and branch behavior are unchanged.
- macOS uses the Unix metadata behavior: hidden paths are names that start with `.`, and read-only metadata follows Unix permissions.
- Windows and Linux release asset names remain unchanged.
