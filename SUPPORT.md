# Support

Snap is currently maintained as a small OSS project.

## Before Asking For Help

Run:

```bash
snap doctor
```

If you are working from source in this repository, use source-built Snap:

```bash
./target/release/snap doctor
```

Also check:

- `README.md`
- `doc/SNAP_DOCTOR.md`
- `doc/KNOWN_LIMITATIONS.md`
- `doc/REPAIR_GIT_ERRORS.md`

## Where To Ask

- Use GitHub issues for bugs, feature requests, and doctor reports.
- Use the security policy for private vulnerability reports.

## What To Include

- Operating system and shell.
- Git version.
- Snap version or commit.
- The command you ran.
- Relevant `snap doctor` output.
- Whether the repository is disposable or contains private work.

Do not paste secrets, tokens, private repository URLs, or private source code into public issues.
